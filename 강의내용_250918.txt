*깃허브 사용시, 반드시 숙지해야할 대원칙
1) 깃허브에 데이터를 푸쉬하고자 할 때, 반드시 루트 폴더 내에서는 .git => 1개만 존재!!!
- .git => staging area

2) 1회 푸쉬 시, 반드시 100메가 바이트를 초과 x
- .gitignore => 푸쉬하지 않고 싶은 파일 및 폴더 목록 입력

3) 복수의 컴퓨터 (*집 // 학원 // 노트북)에서 1개의 깃허브 레포지토리를 사용하려고 하는 경우, 반드시 푸쉬가 우선이 아니라, 풀이 우선이다.

로컬에 깃 설치 여부 확인 : git -v
깃 소유주 정보 확인 : git config --list

-- 터미널

루트폴더 안에 최초 한번만 초기화 : git init
루트폴더 & 레포지토리 연결 : git remote add origin 레포지토리 이름
루트폴더 & 레포지토리 연결 확인 : git remote -v
.git 폴더 > 데이터 삽입 : git add .
.git 폴더 > 데이터 삽입 확인 : git status
루트폴더 > 데이터 커밋 : 버전 인덱스 생성 : git commit -m “250918”
github 레포지토리로 실제 데이터를 푸쉬 : git push origin master 

cd .. : 현재의 폴더에서 한 단계 위로 올라간다
cd path 경로 : 해당 경로로 이동하겠다
